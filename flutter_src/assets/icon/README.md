# App 圖示放這裡

把你的 logo 命名為 **`logo.png`** 放在這個資料夾:

    flutter_src/assets/icon/logo.png

## 規格建議
- **尺寸**: 1024 × 1024 像素(正方形)
- **格式**: PNG
- **背景色**: 可在 `pubspec.yaml` 的 `adaptive_icon_background` 調整,
  請設成和圖片相同的底色(目前為綠色 `#B6E3CE`),邊緣才不會露白邊。

## ⚠️ 為什麼主體不要留太多白?(重要)
Android 的「自適應圖示 (adaptive icon)」**本身就自帶安全區** —— 系統只保證
顯示前景圖中間約 **66%** 的範圍,外圈會被縮放/裁掉。

所以如果你的圖**自己又留了很多白**(例如主體只佔 69%),就會變成**雙重留白**:
`69% × 66% ≈ 46%`,主體在桌面上看起來就會**明顯縮小**。

**做法**: 這個專案用兩張圖分工:
- `logo.png`            —— 一般(legacy)圖示,主體置中、可留白。
- `logo_foreground.png` —— adaptive icon **專用前景**,主體已放大到填滿約 **82%**,
  用來抵銷上述安全區縮放,讓山豬在新手機上維持正常大小。

如果之後要換 logo,記得 `logo_foreground.png` 裡的主體要**放大、幾乎填滿畫面**
(留約 10% 邊即可),不要再留 20~25% 的白。

## 放好之後
commit + push,雲端 build 會自動偵測到這張圖並產生所有尺寸的 App 圖示,
不用你手動處理任何 mipmap。若這個檔案不存在,就會沿用預設的 Flutter 圖示。
