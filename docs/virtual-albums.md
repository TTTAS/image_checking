# 我的相簿（虛擬相簿 Virtual albums）

## 這是什麼

在「資料夾」分頁最上方多了一區「我的相簿」，讓你**自己建立相簿把照片分類整理**。

重點是：**這是純 App 內的虛擬分類，完全不會動到手機裡的實體檔案。**

- 建相簿、加入照片、移除、刪除相簿，**都不會搬移、複製、改名或刪除任何檔案**，
  照片永遠留在原本的位置。
- 因此**不需要任何額外權限**（不碰 `MANAGE_EXTERNAL_STORAGE`／「所有檔案存取權」），
  上架 Google Play 不會因為敏感權限被卡。
- 一張照片可以**同時屬於多個相簿**（標籤式歸屬），例如同一張同時放進「貓咪」和「2024 旅遊」。

實作上，相簿只記錄「相簿名稱 → 照片 id 清單」，跟現有的「最愛／隱藏」一樣存在
App 自己的 `SharedPreferences` 裡（見 `lib/src/virtual_albums.dart`）。

## 操作

1. **建立相簿**：在「資料夾」分頁「我的相簿」區塊點 **＋ 新增相簿**，輸入名稱即可。
2. **加入照片**：在任何照片格子長按進入多選，底部工具列點 **加入相簿**
   （🖼️＋ 圖示），勾選一個或多個相簿（也可以當場「建立新相簿」），按確定。
3. **看相簿內容**：點相簿封面進入，裡面就是這個相簿收藏的照片。
4. **從相簿移除**：在相簿內多選照片 → 底部 **移出相簿**，只會把照片移出這個分類，
   **照片本身不會被刪除**。
5. **相簿管理**：相簿內右上角選單可**重新命名／設定封面／恢復預設封面／刪除相簿**。
   刪除相簿只刪掉這個分類，裡面的照片一樣保留在裝置上。

## 幾個一致的行為

- **封面**：預設用相簿裡第一張照片；也可在相簿右上角選單指定任一張為封面。
- **照片被刪掉時**：如果某張照片在裝置上被刪除了，下次打開相簿會**自動把失效的項目清掉**，
  不會報錯（跟「最愛／隱藏」的處理一致）。
- **已隱藏的照片**：被標記隱藏的照片在虛擬相簿裡也**跟著隱藏**，全 App 一致。
