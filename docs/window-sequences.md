# 視窗序列桌布（Window sequences）

## 這是什麼

一張原圖可以切成多個「視窗」（framing），每個視窗有自己的縮放與焦點位置。
整個視窗序列**只占輪播清單的一個項目**：

- **單一視窗＝所見即所得（靜態）**：只裁一個視窗時，桌布就固定顯示你在裁切頁框好的那一塊
  （縮放＋位置完全照裁切結果），套用後與預覽一致、不會隨桌面滑動移動。
- **多個視窗＝同一張圖由左滑／右滑連續平移**：桌面回報的捲動進度會在視窗（關鍵影格）之間連續內插，
  圖片跟著手指平滑地滑過去，**不是一格一格跳的幻燈片**。自動切片的等距視窗＝整張圖平滑左右掃過。
- **不同張桌布（清單項目）會依設定的間隔自動輪換**，預設每 5 分鐘一次，可在「輪播桌布」頁面
  用「自動換桌布」按鈕**自訂時／分／秒**；只有一張時不輪換（單一視窗即靜態，多視窗才隨滑動平移）。滑動時會重新計時。
  （鎖定畫面的靜態輪播因 Android 限制最短約 15 分鐘。）
- 開啟「隨機順序」時只打亂**不同張桌布**的順序，不影響單張內的平移。

一張較寬的圖片（例如電腦桌布），就可以做到「先看左半邊 → 右滑看中間 → 再右滑看右邊」，
把整張橫幅桌布放上手機、靠左右滑動看完。

**自動切片**：在編輯頁右上角按「自動切片」，會把寬圖切成數個「滿高、螢幕寬」的直條視窗、
由左到右覆蓋整張圖（以中央為基準均分），一鍵完成整張可滑的序列。

## 操作

1. 在照片長按多選、或在大圖選「加入輪播」，把圖片加入清單（一張圖 = 一個項目）。
2. 在「輪播桌布」清單點該項目 →「視窗序列」編輯頁。
3. 編輯頁是**可調整比例的上下分割**：上方是**手機螢幕形狀的預覽視窗**（用 ◀ ▶ 選視窗、
   **手指在框內滑動即移動這張圖**，放開即存、拖到邊界自動停不露黑邊），下方是視窗清單。
   **中間的分隔條可以上下拖曳**，即時改變上下兩塊的大小；**拉到最頂會完全隱藏預覽（清單占滿）、
   拉到最底會完全隱藏清單（圖片占滿）**。要放大精修（縮放）就點清單項目進全螢幕編輯。
4. 「新增視窗」：在裁切畫面用雙指縮放/拖曳決定這個視窗要顯示哪一塊，按「使用這個視窗」。
5. 重複新增即可加入多個視窗；點任一視窗可重新編輯，右側把手可拖曳調整順序，也可刪除（至少保留一個）。
6. 回到清單按「套用輪播」。

## 資料模型

- `CropWindow`：單一視窗的 `zoom` / `focusX` / `focusY`。`zoom <= 0` 表示「完整置中」。
- `WallpaperItem.windows`：該項目的有序視窗清單（至少一個）。
- 舊版單一裁切資料（`cropZoom`/`cropFocusX`/`cropFocusY`）會自動遷移成「只有一個視窗」的項目，順序與裁切保留。

## 播放（原生）

- 動態桌布 `PlaylistWallpaperService`：每個 item 保留自己的媒體檔＋一組 `windows`（關鍵影格）。
  `onOffsetsChanged` 只更新連續捲動值 `xFrac`，`computeTransform` 依 `xFrac` 在關鍵影格之間
  內插縮放與焦點後**重繪同一張點陣圖**（不重載），因此是平滑平移而非跳格；單一 zoom 視窗則把
  可視範圍沿整張寬度連續平移。**不同 item 之間**以 `intervalMinutes`（預設 5 分鐘）用 Handler
  計時輪換（只有一個 item 時不排程）。GIF/影片原地播放/循環，平移時下一幀套用新位移。
- 靜態輪播（僅鎖定畫面且全為靜圖時）：`renderCropSave` 會為每個視窗預先算出一張螢幕大小的圖，
  當成輪播影格；靜態模式沒有滑動概念，視窗只是多幾張輪播影格。

## 尚待實機驗收

本次改動在無 Android 裝置的環境完成，下列需在實機或模擬器確認：

- 主畫面右滑/左滑能逐格循環移動視窗（每翻一頁前進／後退一格），滑動途中不會閃出中間影格。
- 部分桌面（launcher）會鎖定桌布捲動而完全不回報翻頁，此時無法用滑動切換
  （本功能倚賴桌面回報翻頁）。
- 套用後系統動態桌布預覽 → 設定 → 主畫面（或主畫面與鎖定）流程正常。
